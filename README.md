# Personal Portfolio Website

This website is a personal portfolio created as part of an Interactive Arts & Technology course assignment. The purpose of this website is to present information similar to a resume while also practicing basic front-end web development and using GitHub for version control and hosting.

The site introduces who I am as a student, highlights my education, experience, and skills, and includes a visualization page that demonstrates simple SVG graphics created using JavaScript.

---

## Technologies Used

- **HTML** – Used to structure the content of the website.
- **CSS** – Used to style the website and create a clean, responsive layout.
- **JavaScript** – Used to add basic interactivity and generate SVG visualizations.
- **SVG** – Used for creating visual elements programmatically.
- **GitHub Pages** – Used to host and publish the website online.

---

## Website Structure and Navigation

The website consists of two main pages:

- **Home Page (`index.html`)**  
  This page includes an introduction, education, experience, skills, and contact information.

- **Visualizations Page (`visualizations.html`)**  
  This page displays SVG-based visualizations created using JavaScript.

Navigation links are located at the top of the website, allowing users to easily switch between the Home page and the Visualizations page.

---

## Notes

This website was created as a learning project and focuses on clarity, structure, and understanding how code can be used to create and control visual elements.
